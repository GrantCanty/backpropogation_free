# Archived CPAM configurations

These JSON files are the exact settings for the retired CPAM digit, memory,
frontend, predictive-representation, drift, scaling, and gradient-comparison
studies. They remain with the archived results and narrative because their
model names refer to CPAM-specific runners.

Proposal-independent synthetic-stream settings remain active in the repository
root `configs/` directory. For the exact original monolithic command layout,
use source commit `24c59fa` as documented in `../MANIFEST.md`.
